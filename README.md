# gitmesh-testing

Fixture repository for GitMesh's offline test suite.

This repository is not for production use. Its history is intentionally small
and stable so checked-in API fixtures stay meaningful.

## Layout

- `docs/guide.md` — a short guide
- `src/` — a tiny Go program
- `assets/data.txt` — deterministic sample data

## Branch changes

The `feature/update-readme` branch adds this section and `docs/changes.md`.
